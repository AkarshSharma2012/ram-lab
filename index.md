# Ram Lab

Agent reliability experiments and forensic reporting. **Planning stage. Application implementation has not started.**

The plan covers real agents building or repairing small apps, completing source-grounded practice assignments, and solving multi-step math problems. Controlled stress and failures test correctness, durable recovery, side effects and factual claims.

- [Read the implementation plan](https://github.com/AkarshSharma2012/ram-lab/blob/main/docs/plan.md)
- [Read the Excel reporting specification](https://github.com/AkarshSharma2012/ram-lab/blob/main/docs/excel-spec.md)
- [View the public repository and change history](https://github.com/AkarshSharma2012/ram-lab)

GitHub Pages hosts these static documents. Agent execution and process fault injection require the proposed local runtime. Any example data added during planning is explicitly synthetic and is not an agent benchmark result.
